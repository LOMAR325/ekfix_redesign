# Отчёт: сайт из двух веток (two-branch-site), 2026-09-29/30

Работа велась без автопилота (по просьбе владельца), по плану `plan.md`. Ветка `autopilot/two-branch-site`
от закрытого прогона entity-commercial-geo (bf4aa91; в main он не влит).

## Что сделано

- **Страница выбора `/`**: один H1 «Appliance repair in Charlotte, NC», две панели — For Business (слева, 60%,
  лаймовая рамка, акцентная кнопка) и For Homes (40%, вторичная кнопка). В панелях по 5 ссылок на ключевые страницы
  ветки. Минимальная шапка: логотип и телефон. Тонкий подвал: имя, телефон, часы, город, соцсети, About, Reviews.
  Обычный серверный HTML: без модалок, JS-шлюза и редиректов, работает с выключенным JS. GA4 `branch_select`.
- **Каркас**: группы маршрутов `(entry)`, `(commercial)`, `(residential)`, `(shared)` со своими layout. URL не
  изменились. Три шапки и четыре подвала, переключатель веток в верхней строке на всех ширинах, логотип ведёт на
  корень своей ветки.
- **Коммерческая главная** `/commercial-appliance-repair` и **бытовая главная** `/appliance-repair` — полноценные
  главные со своими блоками и формами (состав — ниже).
- **Две формы, один `/api/book`**: размеченное объединение по `branch`, zod на каждую форму. Тема письма о
  коммерческой заявке начинается с `[BUSINESS]`. GA4-события отдельно для каждой формы. `contactAs` и
  `BookingProvider` удалены. Пресеты формы передаются через URL.
- **Связи веток из данных**: на 8 бытовых услугах ссылка «Need this for a business? →», на 5 коммерческих
  equipment-страницах обратная «Need this at home?». Ballantyne подан как бытовая страница, коммерческие
  формулировки перенесены в `#service-area` коммерческой главной, на самом Ballantyne осталась одна ссылка туда.
- **Хвосты прошлого прогона**:
  - 7.1: звёзды `aria-hidden`, рядом всегда оценка текстом.
  - 7.2: у 4 городов убраны общий абзац и общие отзывы, шаблонность теперь 0.12–0.14 (было 0.33–0.44). Вопрос
    владельцу не понадобился.
  - 7.3: слово «Google» убрано отовсюду, везде «5.0 · 6 reviews».
  - 7.4: 16 фото переименованы в описательные имена.
  - 7.5: черновики не тронуты.
- **Боковой навигации нет нигде.** Бриф её просил, я её вернул, но владелец напомнил своё решение, и она убрана.

## Как прежние блоки распределились

| Прежний блок | Куда |
|---|---|
| hero `/` (две кнопки) | страница выбора; hero-стиль — в обе главные |
| #who-we-serve | коммерческая `#industries` (сегменты хаба); карточка «Homeowners» ушла (её роль — страница выбора) |
| #commercial-equipment (4 карточки) | коммерческая `#equipment` (5 equipment-страниц) |
| #trust-b2b | коммерческая, сразу после hero |
| #repair (12 карточек) | бытовая `#repair`, карточки ведут на страницы услуг |
| #family (+ Where we work) | бытовая `#family` (портрет, без коммерческих фото и фразы про ресторан) + отдельный `#areas` |
| #reviews | бытовая — отзывы домовладельцев; коммерческая — отзыв ресторана |
| #brands | бытовая — бытовые и премиальные; коммерческая — коммерческие + «Also serviced» |
| #business-cta | удалён (роль у hero и `#request` коммерческой) |
| #book (общая форма) | бытовая `#book` (HomeBookForm) и коммерческая `#request` (BusinessRequestForm) |
| хаб: сегменты, #laundry, #process, #formats, why, FAQ | коммерческая главная, все якоря сохранены; к #formats добавлен абзац о договоре |
| бытовой хаб (сетка 12) | бытовая главная |
| новое | бытовая `#pricing` ($75 / 10% / цена до работ) и `#faq` — из опубликованных фактов; коммерческая `#service-area` |

Главные не повторяют друг друга. Общие id секций — только `top` и `brands`. Сходство текста по Жаккару
(3-словные шинглы): вся страница 0.023, основная часть 0.013 (`qa/homes-similarity.txt`).

## Решения

- ADR 0022 — сайт из двух веток: группы маршрутов, шапки и подвалы, страница выбора, распределение блоков.
- ADR 0023 — две формы и один обработчик, пресеты из URL, GA4.
- Приписка к ADR 0002 — блок стилей `branch-*` и шапка на 1025–1099px.
- ADR 0021 заменён. ADR 0010 и 0016 уточнены.

## Вопросы владельцу

1. Где опубликованы 6 отзывов (Google? факт 11)? Только после ответа можно вернуть «on Google».
2. У коммерческих отзывов пока один (Tony Z., ресторан). Есть ли ещё отзывы бизнес-клиентов?
3. Реальные фото коммерческого оборудования (факт 13). Карточки equipment пока с бытовыми фото-заглушками.

## Шаги вне кода

- Влить ветки entity-commercial-geo и two-branch-site в main и задеплоить. Это делает владелец; push я не делал.
- В GA4 отметить события `branch_select`, `commercial_form_submit`, `residential_form_submit` как ключевые.
- Заполнить `RESEND_API_KEY` и `BOOK_NOTIFY_EMAIL` в `.env`, чтобы заявки приходили на почту; в почте настроить
  фильтр по `[BUSINESS]`.
