## Что сделать

1. `qa/pages.mjs` (Playwright из npx-кэша, не зависимость проекта) по `publishedPaths()` на 1440×900 и 390×844 против `npm start`: контраст видимого текста (WCAG, ≥ 4.5:1 для обычного текста), `scrollWidth ≤ innerWidth`, ошибки консоли, `<img>` c `naturalWidth > 0`; H1 главной — строки; первые две кнопки hero. Отчёт — `qa/pages-report.md`.
2. `qa/jsonld.mjs` по prod-HTML: парсинг, один `@graph`, разрешение `@id`, один бизнес, Person без фамилии, **сверка всех строковых значений с видимым текстом страницы** (история 82). Отчёт — `qa/jsonld-report.md`.
3. `npm run check:copy` — пусто по жёсткому списку; ручной разбор `best/most/leading` — в отчёт.
4. `npm run check:similarity` для групп `areas` и `commercial` (против `npm run dev`) — матрицы в `qa/similarity-report.md`; сверить, что опубликованы только прошедшие ≤ 0.30.
5. Черновики: список всех `draft`-единиц → в prod по URL 404, нет в sitemap/меню/HTML-ссылках/JSON-LD — `qa/drafts-report.md`.
6. Редиректы: `curl -sI` таблица (как в таске 09) — `qa/redirects-report.md`.
7. Всё найденное — исправить точечно (в любой зоне; ты один в волне). Не лечится без нового CSS/факта — в CONCERNS.
8. ADR (по образцу `docs/adr/0013`, на русском, «Контекст / Решение / Почему / Последствия», со ссылками на отменяемые): копия в `data/` (отменяет 0011, дополняет 0001); единый draft/published + dev-превью; `/for-business` → `/commercial-appliance-repair` + дочерние (отменяет 0009); районы под `/towns` (дополняет 0008); граф JSON-LD с `@id` (дополняет 0007); `data/guides.ts` как формат (R77); боевой домен ekfix.us + редиректы старого ekfix.us (отменяет 0005, дополняет 0013); меню и «Home Appliances». В отменяемых ADR — строка «Отменено ADR 00NN» в заголовке (как 0012).
