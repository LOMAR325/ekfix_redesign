# 0024. Отзывы из Google: Places API при сборке и раз в сутки, свои отзывы — запасной вариант

## Контекст

На сайте 6 отзывов из `data/reviews` (перенесены со старого сайта; где они опубликованы, не было
подтверждено — поэтому в прогоне two-branch-site убрано слово «Google»). Владелец (2026-09-30) хочет
на сайте реальные отзывы прямо из Google и дал ссылку на свой профиль: `https://g.page/r/CQzbpOh98VJ2EAE/review`.
Из выбора «Google API / виджет / вручную» выбрал Google API.

## Решение

- `lib/google-reviews.getReviews(): ReviewsData` (`{source: "google" | "site", rating, reviews}`).
  При заданном `GOOGLE_PLACES_API_KEY` — Places API (New), Place Details по Place ID бизнеса
  (`data/business.google.placeId`, взят из редиректа ссылки владельца), маска `rating,userRatingCount,reviews`,
  `fetch` с `next.revalidate: 86400`. Страницы с отзывами становятся ISR: обновляются при сборке и раз в сутки.
  Без ключа, при ошибке Google или без пригодных отзывов — отзывы сайта (`data/reviews`); сборка без ключа
  остаётся полностью статической.
- Где показываются: hero обеих главных (оценка текстом «4.9 · 27 Google reviews» / «5.0 · 6 reviews»),
  `#reviews` бытовой главной, блок отзывов коммерческой, `/reviews` (при Google — одним разделом: сортировать
  отзывы Google по технике нечем), плашка рейтинга Charlotte.
- Карточка отзыва Google: свои звёзды (1–5), имя автора — ссылка на его профиль Google, «2 weeks ago»;
  под блоком — подпись «Reviews from Google Maps» (атрибуция, которую требует Places API) и две ссылки:
  «All reviews on Google →» (профиль) и «Leave a review →».
- Профиль Google добавлен в соцсети подвалов и в `sameAs` узла бизнеса.
- `aggregateRating` в JSON-LD — только когда показаны отзывы сайта. Отзывы Google размечать на своём сайте
  нельзя (правила Google для review snippets: только отзывы, собранные самим сайтом).

## Почему так, а не иначе

- **Виджет стороннего сервиса** — отвергнут владельцем: чужой JS, часто платно, отзывы не видны поисковикам.
- **Вручную** — отвергнут: новые отзывы не появлялись бы сами.
- **Places API в браузере** — отвергнут: ключ оказался бы в клиентском коде; запрос идёт только на сервере.
- Ограничение API: Google отдаёт до 5 отзывов («most relevant»), поэтому ссылка на все отзывы обязательна.
  Контент Google не записывается в репозиторий и не хранится дольше суток.

## Последствия

- Шаг владельца: создать ключ Places API (New) в Google Cloud, ограничить его Places API и вписать
  `GOOGLE_PLACES_API_KEY` в переменные окружения Vercel (Production), затем передеплоить.
- Пока ключа нет, сайт показывает прежние 6 отзывов без слова «Google» (ADR 0022, хвост 7.3).
- Тесты: `lib/google-reviews.test.ts` (без ключа, успешный ответ, ошибки, пустой ответ).
